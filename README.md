# Estadística · Grupo 05 · ESPE

Portafolio web del proyecto de análisis de datos. Responsable: Axel Revelo.

## Contenido
- Tres parciales y un índice de contenidos.
- Buscador, filtros y accesos a los archivos del equipo.
- Catálogo en `recursos.js`, que se puede actualizar con `editar-enlaces.html`.

## Publicación gratuita
GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

La dirección será: https://axelrevelo075-alt.github.io/Estad-sticaa/

## Agregar recursos
1. Abre `editar-enlaces.html` en el navegador.
2. Completa o agrega los enlaces de Google Drive.
3. Descarga `recursos.js`.
4. Reemplaza ese archivo en este repositorio (rama main).

Carpeta original: https://drive.google.com/drive/folders/1v25o8y0S-ThMb_HCe02XVSFLf07gldvm

**Aviso:** únicamente están verificados los enlaces de las carpetas generales; los demás son casillas preparadas para agregar los documentos del equipo.
